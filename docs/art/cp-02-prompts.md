# Case 2 (cp-02) — ChatGPT image prompts

Made by the content owner in ChatGPT. Save each image as PNG into
`content/assets/art/cp-02/` using the file name shown for each panel.

How to use
1. Open a new ChatGPT chat. Upload ONE case 1 picture that shows only the doctor and the nurse
   (case 1 panel 7, `07-reperfusion-pci`), then paste **Setup**, then **New characters**. Don't upload a
   picture with the case 1 patient in it: ChatGPT copies him (first attempt, 2026-10-01).
2. Paste the panel prompts **one at a time**: one picture per message, full size. Don't ask for a
   sheet of all the panels; it comes out too small for the app.
3. If a face or the style drifts, say "Match the reference image and the earlier panels exactly" and
   regenerate.

People are placed left to right in the order the app expects, so the speech-bubble tails point at
the right person. Keep that order if you re-roll.

8 pictures. Afternoon daylight throughout (this case starts at 2:30 p.m.).
