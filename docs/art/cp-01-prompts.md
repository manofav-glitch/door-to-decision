# Case 1 (cp-01) — ChatGPT image prompts

Made by the content owner in ChatGPT. Save each image as PNG into
`content/assets/art/cp-01/` using the file name shown for each panel.

How to use
1. Open one new ChatGPT chat and keep every image for this case in it.
2. Paste **Setup** first, then **Character sheet**. Re-roll until you like the cast.
3. Then paste the panel prompts one by one. If the style or a face drifts, say
   "Match the character sheet and the earlier panels exactly" and regenerate.
4. If you have to start a new chat, paste Setup again and upload the character sheet image.

Panels 10 and 18 are monitor close-ups: they stay code-drawn because they show the live
numbers. Panels 8 and 9 may reuse the image from panel 7 if you want to save time.

---

## Setup (paste once, first)

```
'm making square comic panels for a medical-education app. For EVERY image in this chat:
- Square 1:1 format.
- Style: muted retro storybook illustration, flat gouache colours, soft shading, visible paper grain, clean dark ink outlines. Warm, slightly desaturated palette: cream, teal, dusty orange, slate blue, olive.
- Setting: a busy government-hospital emergency department in India. Realistic and respectful, never gory.
- Composition: people and action in the lower two-thirds. Keep the TOP THIRD quiet and plain (wall, ceiling or sky) because speech bubbles will be added there later.
- NO text of any kind: no letters, numbers, signs, labels, logos, watermarks or speech bubbles. Monitor screens show only soft glowing lines, never readable numbers. ECG paper shows faint lines, never readable.
- Keep the same characters, faces, clothes and style in every image.
Reply "ready" and wait for my prompts.
```
